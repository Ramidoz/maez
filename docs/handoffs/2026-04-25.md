### `621f44e` — official-label isolation

The named risk: calibration/noise probe runs (matcher tweaks, smoke
tests, false PASSes from too-loose verdicts) were all writing into
the same ledger as canonical runs. Heartbeat consumed everything.
A noisy weekday morning of probe iteration could pollute the daily
self-summary.

The fix:

- Probe ledger writer adds `ledger_label="official"` by default
  (calibration runs can opt out)
- `summarize_day` defaults to `label="official"` AND
  `latest_run_only=True` — only the most-recent canonical run
  feeds the heartbeat
- Old unlabeled rows are NOT deleted — Maez's never-delete-memory
  rule applies to the ledger too. They stay; summary just filters

Verified live: the ledger has 144 total rows today (54 unlabeled
legacy + 90 official); `summarize_day('2026-04-25')` returns
"Continuity probes today: PASS=15, FAIL=0, FLAG=0 of 15 across
scenario. No objective regressions recorded." — the 15 from the
latest official scenario run, no pollution from the 54 legacy
rows.
