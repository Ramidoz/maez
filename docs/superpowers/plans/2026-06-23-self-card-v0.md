# Self-Card v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, read-only self-card that replaces the hardcoded focused-cognition voice card behind shadow and enabled flags.

**Architecture:** Add a small `core.routing.self_card` assembler that reads `soul.base.md`, selects a bounded/deduped recent slice from `soul.local.md`, computes one body-state line, and returns text plus a content-light receipt. Wire `core.routing.focused_cognition` so `MAEZ_SELF_CARD_SHADOW` logs the real assembled-card receipt while preserving legacy prompt text, and `MAEZ_SELF_CARD_ENABLED` swaps the assembled card into focused and lean prompts.

**Tech Stack:** Python stdlib, `unittest`, existing `core.infra.paths`, existing `core.infra.runtime_services`, existing `maez.focused` logger.

---

## File Structure

- Create `core/routing/self_card.py`: deterministic assembler, local-note selector, forbidden style directive scanner, content-light receipt.
- Modify `core/routing/focused_cognition.py`: self-card flag helpers, safe assembly, shadow receipt, optional card threading through `_lean_system_prompt` and `_full_focused_system_prompt`.
- Create `tests/test_self_card_v0.py`: assembler, bounded local selector, provenance, no mutation, no style directive, content-light receipt.
- Modify `tests/test_lean_conversation_path.py`: integration tests for shadow-only and enabled replacement.
- Add `docs/proofs/2026-06-23-self-card-v0-task0.md`: Task-0 verification of the real `soul.local.md` structure and focused seam.
