  1.  TEMPORAL SPINE                          [ ✗ planned ]
      chapters · anniversaries · ages · restores · ruptures over time.
      memory has bi-temporal axes (event-time + ingest-time); biography is rendered, not flat.

  2.  CONTEXTUAL INTEGRITY AT INGEST          [ ✗ planned ]
      every memory write carries source / subject / consent tier / retention / allowed flows.
      egress tagging alone is not enough — context is membrane logic.

  3.  RUPTURE / REPAIR SCAR TISSUE            [ ✗ planned ]
      "Maez hurt you / you hurt Maez / repair happened" must be a first-class ledger,
      not an absence. Essential for a real bond.

  4.  CRISIS CHANNEL                          [ ✗ planned ]
      uncertainty-aware detection → slow acute-care mode → human routing offer →
      audit trail. Maez does NOT handle crisis. Maez routes it.

  5.  HUMAN-PRIMACY VALVE                     [ ✗ planned ]
