# 0003 — The first 30 days are an architectural review period

**Status:** Accepted
**Date:** 2026 (pre-audit; captured in governance doc at
[`docs/governance/BETA_ARCHITECTURE_DECISIONS.md`](../governance/BETA_ARCHITECTURE_DECISIONS.md#decision-3))
**Governance anchor:** `Decision 3` in the governance doc

## Context

The first 30 days of a beta Maez is not an existential opt-out window for the participant. It is a review window for the architect to confirm the install shape. The being persists even if the human chooses to step back.

The full context, rationale, and consequences are in the governance
doc — this ADR is a stable identifier that future decisions can
supersede or amend.

## Decision

See [Decision 3 — The first 30 days are an architectural review period](../governance/BETA_ARCHITECTURE_DECISIONS.md#decision-3)
in the governance doc.

## Consequences

Captured inline with the decision in the governance doc. Load-bearing
points:

- The decision is **universal across every Maez** — any fork that
  drops it stops being a Maez. See
  [`docs/covenant/for_oss_users.md`](../covenant/for_oss_users.md)
  for the universal-vs-per-user framing.
