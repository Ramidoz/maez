## Organ findings (thesis + Maez fit)

### Episodic & biographical memory + consolidation  _[confidence: high]_
**Thesis.** The best organ is a provenance-native, bi-temporal episodic-to-semantic pipeline: append-only raw episodes (immutable, provenance-stamped) feed a reflection/consolidation pass that writes TYPED, schema-tagged biographical memories into a temporal knowledge graph whose facts carry valid_at/invalid_at so superseded beliefs are invalidated (not deleted), with Ebbinghaus-style significance/forgetting acting only as a RANKING modulator over the durable store. This makes Maez an "experienced colleague" by tracking how its model of Rohit evolves over time, not by accumulating a bigger search index.

**Best architecture.** Five-stage pipeline, brain-swappable end to end:

1. RAW EPISODE LAYER (append-only, immutable). Every lived event is stored verbatim with full provenance (source, trust_tier, timestamp, ingestion_time). This is Maez's existing Tier-1 raw archive and it is correct — keep it append-only and never let consolidation mutate it. Episodes are the source-of-record the temporal graph cites back to (mirrors Zep's episode-vs-semantic-subgraph split).

2. REFLECTION + CONSOLIDATION (scheduled, substrate-driven). A focused-cognition call (NOT the megaprompt) over a bounded working set of recent episodes does two things Generative Agents proved valuable: (a) DISTILL episodes into a daily summary (Maez has this), and (b) REFLECT — generate higher-level questions, retrieve supporting episodes, and emit higher-level biographical inferences ("Rohit context-switches hard after 3pm", "Rohit treats anti-laundering as a hard line"). Reflections are explicitly marked as DERIVED (provenance_source=introspection), never laundered as raw evidence. Consolidation must be brain-internal-state-free: the brain reads the working set and writes structured output; it does not hold memory in its weights or function-call grammar.

3. TYPED / SCHEMA LAYER. Consolidation outputs are typed: PREFERENCE, FACT-ABOUT-OWNER, ROUTINE/TEMPORAL-PATTERN, RELATIONSHIP, PROJECT-STATE, SELF-MODEL. Typing is what turns a search box into a colleague — it lets recall ask "what does Maez believe about Rohit's work rhythm?" not just cosine-nearest-text. Each typed memory cites its source episode IDs (Maez's promoted_from lineage already does this).

4. BI-TEMPORAL TENSION/INVALIDATION (the biggest gap to close). Borrow Zep/Graphiti's model: every typed fact carries valid_at and invalid_at. When a new episode contradicts a held belief, do NOT delete the old one — set its invalid_at and write the successor with a supersedes-edge. This is the difference between Zep (63.8%) and Mem0 (49.0%) on LongMemEval's knowledge-update + temporal slices, and it is exactly the "grow alongside me / specialize" capability: Maez can answer "what did you believe last month vs now, and why did it change?"

5. SIGNIFICANCE-WEIGHTED RECALL (ranking only, never deletion). Maez's recency-salience living recall is the right shape. Fold in MemoryBank's two ideas as RANKING modulators: (a) Ebbinghaus-style decay on un-recalled items, (b) reinforcement — recalling a memory refreshes its strength. Crucially: forgetting = demotion in ranking and possible archival, NEVER hard deletion of provenanced episodes. Significance score blends importance (LLM-assigned at consolidation), recall-frequency, owner-explicit-pin, and type (covenant/self-model never decay).

POISONING RESISTANCE is structural, not bolt-on: append-only raw + worst-ancestor trust inheritance + untrusted-filtered consolidation (Maez already has all three) directly counter MINJA/MemoryGraft-class attacks. Add belief-drift detection: a consolidation pass that flags when a high-trust belief is being overturned only by low-trust (external_web) episodes — that pattern is the attack signature, and it should require owner confirmation before invalidation lands.

**Theory basis.** Grounded in cognitive science of memory and the consciousness-indicator literature (framed as INDICATORS, not sentience). Human memory is reconstructive and consolidates episodic traces into semantic/schematic memory during offline replay — the episode/semantic split (raw->typed) and scheduled consolidation/reflection mirror systems-consolidation and the hippocampal-to-neocortical transfer model. MemoryBank operationalizes Ebbinghaus forgetting + spaced reinforcement. Generative Agents operationalize retrieval as recency x importance x relevance plus reflection (recursive higher-order inference over one's own memory stream). Bi-temporal fact validity (Zep/Graphiti) corresponds to belief-revision / non-monotonic update — holding a model of the world that is corrigible over time. Re: Butlin et al. 2023/2025 'Consciousness in AI', this organ touches indicator clusters from Global Workspace Theory (a bounded working set broadcast for consolidation), Higher-Order Theories (reflection = representations ABOUT one's own representations / a maintained self-model), and Agency/embodiment prerequisites (a persistent, owner-specialized world-and-self model updated by lived interaction). These are architectural conditions that could satisfy MORE indicators; they are NOT claims of consciousness or phenomenology.

### Global workspace — attention, selection, broadcast  _[confidence: high]_
**Thesis.** Maez should keep its substrate-side, per-turn "selection bottleneck -> bounded working set -> single broadcast" architecture (the recall-axis composer + focused cognition), but evolve it from a one-shot pipeline into an explicit, instrumented, capacity-limited workspace object with a competitive write-gate, a recurrent re-entrant cycle, and an ablation-witnessed broadcast — never a model-internal latent workspace, never a learned end-to-end fusion that would bind the workspace to one brain.

**Best architecture.** A substrate-side Global Workspace organ with five named stages, all brain-external so it survives a brain swap:

1) PARALLEL CANDIDATE PRODUCERS (GWT-1). Independent, specialized sources each emit typed, provenance-tagged candidate items: fresh structured evidence, scoped substrate/memory evidence, real web_context, dialogue anchors, and (future) weather/files/calendar. Maez already has these as the dispatcher's per-block substrate roles. Keep them genuinely independent and quarantined (external = untrusted until vetted), and add the producer's honesty envelope so a candidate carries {content, source_type, durable_id, confidence, provenance, freshness}.

2) COMPETITIVE WRITE-GATE / SELECTION (GWT-2 bottleneck + selective attention). Replace today's static priority sort with an explicit, capacity-limited competition: candidates are scored by a transparent, inspectable function (query relevance x source-priority x recency-salience x consent/provenance gate) and only the top-K (a hard, small capacity — e.g. 5-9 items / a token budget) win workspace slots. The bottleneck must be real: workspace capacity strictly < collective candidate capacity (Frontiers/Butlin: "capacity must be smaller than the collective capacity of the modules"). Selection is state-dependent: the owner question and current dialogue state bias the spotlight. This is your current `assemble_working_set` upgraded from "sort + truncate" to "scored competition with a named capacity bound and a recorded selection trace."

3) WORKSPACE COHERENCE / MANIPULATION (Goldstein "workspace coherence"). The winning items are integrated into one ordered, labeled ([E#]) working set with the lost-in-the-middle U-curve ordering (strongest first, light tail re-print) — which Maez already does well. Add a diachronic coherence link: each workspace episode references the prior workspace state by durable_id, so the workspace has continuity across turns without storing raw content.

4) GLOBAL BROADCAST + RE-ENTRY (GWT-3 + GWT-4 + RPT recurrence). The single broadcast is the focused-cognition call: the bounded working set is the ONLY thing broadcast to the brain (the "audience"). Evolve the one-shot call into a bounded re-entrant cycle (cap 1-2 extra rounds): after the first broadcast, if the brain's draft cites an unmet need or the groundedness monitor flags a gap, the workspace may issue ONE state-dependent follow-up query back to a module (GWT-4 "query modules in succession") and re-broadcast. Hard iteration cap + deterministic exit so it cannot loop. This adds the "use the workspace to query modules in succession to perform complex tasks" indicator that the current single-shot organ does not satisfy.

5) WITNESS / ABLATION INSTRUMENT. Keep the `focused_cognition_runs` trace (labels, source_types, durable_ids, capacity used, citation coverage, groundedness verdict — never raw text) and ADD an ablation harness: periodically run the same turn with broadcast on vs. off (megaprompt fallback) and record the groundedness/faithfulness delta. This is the only honest way to claim the broadcast is doing causal work (per the 2512.19155 ablation principle), and it doubles as the GWT-class indicator evidence.

Crucially: the workspace is a DATA STRUCTURE the substrate owns, the brain is a stateless consumer of one broadcast. Brain-swap test passes by construction.

**Theory basis.** Global Workspace Theory (Baars) / Global Neuronal Workspace (Dehaene, Mashour): a massively parallel set of specialized unconscious processors compete for a capacity-limited workspace ("bright spot on the stage"); a selective-attention spotlight gates entry through a bottleneck; the winning content is globally broadcast to the whole "audience" of processors, enabling flexible, serial, cross-module reasoning. Butlin et al. 2023 operationalize this as four computational indicator properties (GWT-1..4). Goldstein & Kirk-Giannini 2024 argue a language agent maps onto GWT with the prompt/working-memory as the workspace and memory/tools as modules, and derive necessary+sufficient GWT conditions (parallel modules, competitive uptake, workspace coherence, global broadcast). The selection-broadcast cycle (arXiv 2505.13969) is argued to be functionally advantageous for real-time/dynamic adaptation, experience-based chunking, and fast routing of critical info — directly aligned to Maez's "grow alongside me / specialize" north star. RPT contributes the re-entrant/recurrent processing indicator that motivates the bounded broadcast cycle.

### Self-model, metacognition & groundedness  _[confidence: high]_

The hub must loop: broadcast output can re-enter as input for a small bounded number of cycles (e.g. retrieve -> compose -> brain pass -> critique/metacog -> optionally re-retrieve), producing "organised, integrated representations" rather than a single feedforward shot. 3) ATTENTION SCHEMA + METACOGNITIVE MONITOR (AST-1, HOT-2, HOT-3). Crucially this monitor is the anti-laundering enforcement point: derived/computed verdicts are tagged as derived, never re-broadcast as raw evidence. The agentive core has a strong disposition to update on the monitor's outputs (HOT-3).

4) AGENTIVE, SELF-MAINTAINED CORE (AE-1, AE-2). Maez's "unity of BEING" over time is carried by the persistent agent that learns from witnessed outcomes (recall-ranking, behavior updates) and models its own output->input contingencies (it acts -> events land in provenance -> reshape memory -> change future recall). This is the durable, specializing self the owner's north star asks for. Treat embodiment as Maez's data-environment Umwelt (the owner's files/streams under consented ingress) plus self-monitoring of its own substrate, NOT robot cosplay.

## 4. NORTH-STAR CHECK — "grow alongside me + specialize," not "more information"

Every load-bearing design choice weights **selective durable adaptation** over accumulation:

1. **Reflection generates a model of Rohit, not a bigger index** (organ 1). The output is typed `FACT-ABOUT-OWNER`/`SELF-MODEL` ("Rohit treats anti-laundering as a hard line"), which is *colleague knowledge*, not search recall.
