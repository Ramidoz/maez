## What to grep for tomorrow

```bash
# Substrate fire rate over the last 24h:
journalctl -u maez.service --since "24 hours ago" --no-pager \
  | grep "entity_expansion fired" \
  | wc -l

# Which semantic phrases actually fire on real traffic:
journalctl -u maez.service --since "24 hours ago" --no-pager \
  | grep "entity_expansion fired" \
  | grep -oE "semantic_phrases=\[[^]]*\]" \
  | sort | uniq -c | sort -rn

# Entities that surface most often:
journalctl -u maez.service --since "24 hours ago" --no-pager \
  | grep "entity_expansion fired" \
  | grep -oE "entity_canonicals=\[[^]]*\]" \
  | sort | uniq -c | sort -rn
```

These three queries together answer "is the substrate paying off in the wild?" — without that data, the next slice would be guessing.
