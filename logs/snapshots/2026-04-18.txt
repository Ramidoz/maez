========================================
LESSONS LEARNED THIS SESSION
========================================

1. max_tokens=3000 is too small for thinking-mode models on reasoning-heavy
   tasks. Thinking eats tokens before content starts. Default should be 8000
   minimum for Qwen3/Ornstein with thinking on.

2. "Silent failure" is often "infra too tight" rather than "model dumb."
   Ornstein looked bad at 3k, was fine at 8k. Always tune the easy knobs
   before blaming the model.

3. N=1 evals are unreliable. Run variance was high across all three models
   — the 5-prompt battery needs at least 3 runs per model per task for a
   real signal. Single-run "Ornstein broken" claim didn't survive a re-test.

4. Capability gaps between near-peer open-source models are small.
   Stock/Ornstein/Gemma4 all landed within ~5 points of each other. The
   real differentiator is FAILURE MODE (safe punt vs confident lie vs silent
   loop), not peak performance.

5. Distillation beats public-reasoning-corpus SFT *for the user's own
   problem distribution*. Public data like OpenThoughts-3 is generic;
   logged trajectories are aligned. The hybrid router is also a data
   collection pipeline.

6. A thin voice wrapper ("— checking with a bigger model —") is more honest
   than a full paraphrase. User sees when the answer is external. Voice
   consistency comes from SFT at training time, not runtime rewriting.

7. Regex classifier beats LLM classifier as a starting point: inspectable
   failures, zero extra latency, legible rules. Upgrade only when real
   miss-rate data demands it.
