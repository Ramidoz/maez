========================================
WHAT WENT WRONG / RIGHT:
========================================

RIGHT — Structured intent replaces fragile diff generation:
Model outputs JSON with target_name + proposed_value. We validate
the intent against real AST-extracted targets, then synthesize the
edit deterministically. The diff is always well-formed because it
comes from difflib, not the model.

RIGHT — Non-blocking trigger:
Trigger now enqueues a job and returns immediately. The worker
thread processes the job asynchronously. The reasoning loop is
never blocked by Ollama.

RIGHT — Live file safety:
The entire proposal pipeline works on in-memory content copies.
The live cognition_quality.py is read but never written. Only the
existing apply rail may modify it.

RIGHT — Worker recovery:
Stale processing jobs are reclaimed or failed after timeout.
MAX_JOB_ATTEMPTS prevents infinite retry loops. All transitions
logged explicitly.

MINOR — Keyword list formatting:
The synthesized edit for list values produces a single-line repr()
instead of the original multi-line format. This is functionally
correct but changes the file's visual formatting. A future
improvement could preserve the original indentation style.
