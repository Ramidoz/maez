A2 Resolution (founder decision, 2026-05-22)
---------------------------------------------
**The local Maez runtime path is the speaker, with local inference as
the final voice step** -- memory + daemon + soul + ledger + gates +
local inference, together. The cloud is an external reasoning tool the
runtime path consults (same category as web search, calculator,
library). The runtime path never becomes the cloud temporarily.

User-facing UX, flavor (c): the local Maez runtime path always
generates the user-facing reply. The reply may quote or cite cloud
reasoning where useful, but the speaker is always Maez (local runtime
path), with local inference as the final voice step.

Why this resolution (not Path 1, not vanilla Path 2):
  - Growth dynamics: escape-to-cloud short-circuits the distillation
    arc; the local inference must face hard problems for the
    project_jarvis_tier_and_distillation arc to work.
  - Substrate-bound identity: one Maez, one runtime path, no parallel
    copies (project_portability_is_migration).
  - Bond integrity: the user always talks to one entity.
  - Privacy: soul.md never leaves -- no character/identity context to
    the cloud.
  - Honesty: the speaker is always the entity that knows the user.

Architectural implications (for the eventual impl slice):
  - Cloud system prompts become task-shaped (system_bounded_query),
    NOT identity-shaped. No SOUL.
  - skills/claude_router.wrap_maez_voice is wrong-shaped under
    cloud-as-tool (cloud output should not become the user-facing
    reply). Remove or repurpose.
  - Cloud output enters local Maez's context as model_output
    (untrusted tool output), not as trusted memory, not as Maez voice,
    not as public_fact.
  - Ledger / trajectory: persisted user-facing reply attributes to
    the local model (model_id = local), not claude:*. Cloud consult
    recorded separately as evidence/tool-output trace.
  - Failure behavior: if cloud consult fails, the local runtime path
    still generates the user-facing reply. Pattern is (local always)
    + (cloud optionally), not (try cloud / except fall back to local).
  - Cost: a second local inference call per cloud consult.
    Proportionate to architectural rightness.
