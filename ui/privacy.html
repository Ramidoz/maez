Privacy, plainly stated

What we see. What we don't.

Maez is built on memory. That only works if you can trust where the memory lives. This page exists so you don't have to guess. No third-party scripts, no fingerprinting, no surveillance business model. Everything below is how the site actually behaves today — not a promise about tomorrow.

What the site analytics collects

  • Anonymous pageviews — which routes people visit
  • Explicit CTA clicks — which buttons get pressed
  • Coarse device bucket — desktop, mobile, or tablet
  • Referrer grouping — roughly where a visit came from
  • Timestamp of the event

What it explicitly does not collect

  • Your chat messages or Maez's replies
  • Your planner notes, private ideas, or scratch work
  • Your IP address, precise location, or device fingerprint
  • Identifiers tying you to other sites you visit
  • Anything from third-party scripts — there are none loaded
02
Where it lives

Your data stays here.

Site analytics
Written to a local append-only file on the machine that runs Maez. Never leaves this server, never ships to any analytics provider, never joins an ad network.
Your conversations
If you create an account, your conversations with Maez are stored per-user in an isolated memory store on the same machine. Other users cannot see your memory. This is what lets Maez remember you across sessions — it is the whole promise of the product, not a side effect.
Account data
Username, a display name you choose, and a password hash. Email is not required. The less we hold, the less there is to worry about.
Cookies & local storage
One authentication token (maez_token) so you stay signed in. No ad cookies, no analytics cookies, no cross-site trackers. Clearing your browser storage signs you out — nothing else breaks.
Third-party calls
Google Fonts is used for typography, which means your browser fetches fonts from Google's CDN. Everything else — the brain (Gemma 4, running on llama.cpp), the memory, the reasoning — runs locally on the Maez machine in . No OpenAI, no Anthropic, no cloud model provider in the loop.
03
Your choices

You are in control.

You can browse without an account. The public pages — landing, progress, architecture, this page — do not require a sign-in. Analytics still sees the anonymous pageview, nothing more.

You can talk to Maez without linking other identities. The public Telegram bot and the web channel are separate doorways. Linking them is optional and only happens if you explicitly choose to.

You can ask for your memory to be forgotten. Maez's design philosophy is that nothing is deleted — memory is continuity. But if you want your conversation history removed, reach out via the channels below and the owner will handle it personally.

You can read the code. The public repository at ramidoz/maez is the same code that serves this site. If a claim on this page stops being true, the code will show it first.

If something changes.

Maez is a living project. If the data model ever changes meaningfully — a new feature, a new integration, a new backend — this page is the first thing that gets updated. The live status of the build is on the build log; the wiring is on the how-it-thinks page.
