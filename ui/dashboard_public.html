how memory works

Maez remembers on three levels: raw experience, nightly summaries, and permanent core truths. The point is continuity, not chat history for its own sake.

TIER · RAW
raw archive
0
Every cycle + every exchange. Full perception snapshot in metadata. Topic-tagged across six wings for retrieval.
TIER · DAILY
daily
01
Nightly roll-up by the same merged gemma-4-26B-A4B brain, from the last consolidation timestamp. Forty-eight-hour fallback if fewer than ten memories are found.
TIER · CORE
core
07
Permanent. Always fully injected into every reasoning prompt. Created via Tier-0 action, survives forever.
Invariant. Nothing is ever deleted. Every thought, every interaction, every observation persists across all three tiers. The relationship only deepens.

SECTOR 07 HUMAN-GATED
07

how Maez improves itself safely

Maez can spot weaknesses in its own behavior and propose fixes, but it cannot silently rewrite itself. Human approval is the gate, and rollback protections sit behind that gate.

FIG · 07.1 / EVOLUTION SPINE
AUTO_APPLY_ENABLED = Falsehardcoded No proposal is ever applied without explicit human approval. Two-layer rollback: immediate (py_compile + health fail) and delayed (watchdog regression within 20–30 cycles).
