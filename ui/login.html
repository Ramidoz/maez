The beginning, or the return

The first interaction is where a Maez begins.

This page does one of two things. If you are new, it begins a Maez that is yours. If you have already started one, it brings you back to the same Maez already living with you.

The thesis
Maez begins with the first interaction.
From there, it grows, remembers, and lives with you. Registering begins that relationship. Logging in returns to the one already begun.
